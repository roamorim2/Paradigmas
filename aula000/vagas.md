# Linguagem de Programação Swift

A linguagem de programação **Swift**, criada pela Apple, é amplamente utilizada para o desenvolvimento de aplicativos no ecossistema da maçã (**iOS, iPadOS, macOS, watchOS e tvOS**), além de contar com suporte para **Linux e Windows**.

## Paradigmas de Programação

Ela combina diferentes estilos de programação para dar flexibilidade e poder aos desenvolvedores. Os principais paradigmas suportados são:

### Orientada a Objetos

Suporta **classes, herança** (embora com foco forte em composição via structs e protocolos), **polimorfismo e encapsulamento**.

### Funcional

Oferece suporte robusto a:

- Funções de alta ordem;
- Closures (equivalentes a lambdas);
- Imutabilidade opcional;
- Manipulação elegante de coleções, como `map`, `filter` e `reduce`.

### Orientada a Protocolos

Um dos grandes diferenciais do Swift. Em vez de depender exclusivamente de hierarquias complexas de classes, a linguagem incentiva a definição de comportamentos por meio de **protocolos** (semelhantes a interfaces), promovendo um código mais modular e reutilizável.
